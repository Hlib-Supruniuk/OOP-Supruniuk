У лабораторній роботі 1v5 було створено консольний проєкт на C# та реалізовано клас City. Клас містить приватні поля name і country, публічну властивість Population, конструктор для ініціалізації обʼєктів та метод GetInfo() для отримання інформації про місто. У Program.cs було створено три обʼєкти класу City та виведено інформацію про них у консоль.
